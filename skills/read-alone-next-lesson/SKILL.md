# Read Alone 下一课音频

在当前 Read Alone 项目中完成用户指定课程的音频、课程数据和网页接入。用户只说“下一课”时，取 `src/lessons.js` 已登记课程的最大课号加一；用户指定课号时使用指定值。

## 固定输入

- 音色与参数：`voices/lesson-57-teacher/profile.json`。
- 中英文参考音频及准确转写：按 profile 的 `references` 读取，校验 SHA-256。
- 音色向量：`voices/lesson-57-teacher/speaker-embeddings.npz`，对应模型与校验值在 `features.json`。
- 词表：`words/nce_words.json` 中 `book == 2`、`lesson_seq == 目标课号` 的完整词条。
- 已确认的第 63 课配方、原始合成片段、截取时间及成品：`voices/lesson-57-teacher/recipes/book2-63.json` 指向的文件。

项目根目录是本技能目录所在的 `skills/` 目录的父目录；定位时先解析符号链接。全部生成输入已经独立保存，直接使用参考 WAV 与转写，无需原始视频。

## 工作流程

先读 [环境与文件](references/environment.md)，再按 [生成与验收](references/workflow.md) 执行。

1. 确定课号和标题，核对本课全部单词、词性、音标、中文释义，尤其同形异音词。
2. 使用已保存的 Qwen3-TTS 1.7B Base 8-bit 模型和对应老师参考音色，在 Apple Silicon Mac 合成。保持 profile 的模型、采样参数和中英文音色。
3. 保存本课配方与原始片段；用识别结果和实际静音边界辅助截取完整目标词。每词导出两段保持音高的英文慢读和一段中文释义。
4. 在暂存目录完成识别、格式、SHA-256、整课顺序及留白检查，再接入网页。最终英文只包含目标词，中文包含对应词性与释义。
5. 登记课程，保留已有课程和选课记忆，构建本机与 Mac 页面，验证真实音频加载、播放顺序和切课停止旧声音。
6. 归档本课原始 WAV、输入文字、配方、截取时间、识别报告、成品与生成记录。向用户给出课号、试听文件和打开网页的操作。

ASR 时间戳是截取建议，需结合波形停顿检查起音与词尾。每课使用自己的截取时间。遇到词前提示音、识别歧义或缺音，调整本课配方或截取位置后复核；调整输入文字时使用新的原始片段缓存目录。

保留用户已确认的音色与语速。模型或参考素材不可用时，明确报告缺少的输入，继续完成可独立进行的词表与网页准备。只处理用户本次要求的课程。
