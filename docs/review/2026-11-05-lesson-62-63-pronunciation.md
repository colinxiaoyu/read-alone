# 第 62、63 课单词音频发音问题清单

分析日期 2026-11-05。只做了分析，没改产品文件。

## 方法与口径

- 视频：Mac 上 `docs/63-Lesson 63.mp4`，大小 242538634 B，和本机一致。用 imageio-ffmpeg 抽音轨。Mac 上 homebrew 的 ffmpeg 坏了，缺 `libvmaf.1.dylib`。
- ASR：faster-whisper small（int8，CPU），装在任务目录的临时 venv 里，产品仓的 venv 没动。先整段转写定位，再在窗口内取词级时间戳，最后用 10/20 ms 能量 + 3.5 kHz 以上高频能量逐帧定边界。
- 音高：parselmouth（Praat）`to_pitch_ac`，音高下限 100 Hz，加 octave-jump 惩罚。r 音色看 F3：Burg 法共振峰，上限 5500 Hz。女声 F3 降到 ~2000 Hz 以下才算 r 化。
- t / 爆破音：在 raw、成品里逐帧看「闭塞段（能量掉下去）+ 高频爆破尖峰」。**爆破强度**定义为爆破帧的高频 RMS ÷ 该词元音峰值 RMS，帧长 10 ms。
- 流水线复核（`scripts/generate_cloned_audio.py`）：按 trims 切 raw → RMS（阈值 2.5%）去首尾静音，前后各留 90/120 ms → 4 ms 淡入淡出 → 前后补 80/120 ms 静音 → ffmpeg `atempo`（slow 0.72，normal 0.86，保音高）。
- 听感类判断我没法真去听，凡是没有数值支撑的都标了「推测」。

## 先给结论：t 和词尾辅音的问题不在截取，也不在慢放

1. **trims 没切早。** 两课 21 个词的 trims 终点全部等于 raw 文件的总时长。62 课 13 个单词提示的 trim 是 `[0, raw_dur]`；63 课 6 个词的终点也都等于 raw 时长（circle 2.24、admire 1.68、close 2.72、wedding 1.84、reception 1.28、sort 2.0）。流水线 RMS 去尾后的保留终点也全部等于 trim 终点，没有词尾被切掉。`generation.json` 里每条 `word_interval` 都和 trims 文件一致。
2. **atempo 没把爆破抹掉。** sort 的爆破强度：raw 0.11，slow 成品 0.12（爆破在 1.00–1.06 s），基本没变。threaten、patch、reception 的成品里也都测到了爆破。
3. **根子在合成本身。** 模型给的 t 要么很弱、闭塞很短，要么闪音化（美式 ɾ），要么干脆不除阻。对照视频老师的 sort：

   | | 闭塞时长 | 爆破强度 |
   |---|---|---|
   | 视频老师 sort（856.86–858.08） | ≈250 ms（857.72–857.96） | 0.44（857.98） |
   | 视频老师 sort（859.62–860.46） | ≈150 ms | ≈0.68 |
   | 成品 / raw sort | ≈60–70 ms，且闭塞段里还有浊音残留 | 0.11 |

   成品比老师弱 4–6 倍，所以听上去「t 没发出来」。**这一项要改配方重新合成，改 trims 没用。**

## 整体根因

1. **合成缺音、爆破太弱、t 闪音化**：sort、desolate、authority、root、smoke、flood，部分还有 destruction、quantity。截取和慢放都没有切掉或抹掉什么，trims 终点等于 raw 时长、atempo 前后爆破强度不变，证据见上。要**改配方重新合成**。
2. **美式 r 化**：sort、circle，可能还有 admire。视频里老师明确要求英式、没有儿化音。要重新合成，或者换参考音频。
3. **语调**：sort 平 / 略升、spray 明显升调、blacken 升调而且重音后移、threaten 和 surrounding 平调、flood 和 wedding 的尾巴偏平。这些都在 raw 里就有，不是截取造成的。63 课「The noun: X.」这类提示词下，sort 的目标词虽然在句末，也没有降调。62 课的单词提示（「spray.」「blacken.」）照样出了升调，所以光改提示词格式不能保证语调对，要多出几版按 f0 挑。
4. **词首杂音点 + 空白**：threaten、grass-seed、century、reception、blacken、patch，还有 quantity（成品 slow 0.11–0.30 s）。模型在 raw 开头吐出一个短杂音，trims 起点又是 0，流水线的 RMS 阈值（相对 2.5%）把它当成了语音，于是成品开头先有一个「咔/嘶」，接着 0.2–0.6 s 空白，然后才是词。**这一项改 trims 起点就能修**，上面每个词都给了新起点；终点保持原值，等于 raw 时长。
5. **连读切分**：admire 的「The verb: admire.」里两个词之间没有停顿，起点切在浊音中间。

## 给 codex 的修复建议汇总

- **只改 trims 就行**（不用重新合成）：threaten → `[0.46, 1.04]`，grass-seed → `[0.52, 1.36]`，century → `[0.25, 0.96]`，reception → `[0.24, 1.28]`，patch → `[0.10, 0.72]`，blacken → `[0.17, 0.88]`。quantity 的 trim 起点要在 0.02–0.14 s 这段静音里取，比如 `[0.12, 0.80]`。但这里面 threaten、grass-seed、blacken 还有别的问题，最后多半也要重新合成；重新合成以后 trims 得重新测。
- **要重新合成的**：sort、admire、circle、desolate、smoke、flood、authority、root、spray、blacken、threaten、surrounding、grass-seed。次要的有 wedding、quantity、destruction。
  - 提示词改成单词单独一句（「sort.」「admire.」「desolate.」），不要用「The noun: X.」，避免连读和非句末语调。
  - 每个词换多个 seed（`seed_base` 或单词 seed）出几版，按这几个客观条件挑：
    - 含 t 的词，元音后要有 ≥100 ms 的闭塞，爆破强度 ≥0.3（老师 sort 是 0.44–0.68）；
    - 英式发音 F3 不能低于 ~2500 Hz（sort、circle、admire）；
    - 句末 f0 至少降 6 st，不能是升调；
    - 双音节以上的词，f0 峰值要落在音标标的重音音节上。
  - 可以考虑：63 课直接用视频老师的片段（上面的 best 片段）当英文 `ref_audio` 做克隆参考，这样更接近老师的英式发音和降调。不过现在 profile 的参考音频是第 57 课的整句（`ref_text` 要和音频严格对应），换参考是改音色 profile，牵涉到 `voices/lesson-57-teacher/profile.json` 和 speaker embedding，**要 colin 拍板**。
- **慢放算法不用换**：实测 atempo 0.72 / 0.86 前后爆破强度一致。
- 校验脚本可以加两条自动检查：词首杂音（开头 0.15 s 内能量超过阈值、紧接着 >150 ms 静音），以及 t 爆破强度阈值。这个由 colin 决定要不要加。
